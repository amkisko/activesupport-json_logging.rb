# Encode with JSON.generate for json 3

## Intent

json 3 removed `JSON.fast_generate`. 1.3.2 still called it on line and structured-hash encode paths, so apps that resolved json 3 failed at boot or first encode with `NoMethodError`.

## Change

Call `JSON.generate` everywhere those paths previously called `JSON.fast_generate`. Add a regression that hides `fast_generate` and checks simple string and large structured hash output. Ship as 1.3.3.

## Notes

Upstream deprecation text already pointed callers at `JSON.generate`. No gemspec constraint change; `>= 2.21.2` still admits json 3.
