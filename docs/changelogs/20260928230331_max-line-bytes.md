# Whole-line byte budget

## Participants

- vesan

## Decisions

- Ship JsonLogging.max_line_bytes as an opt-in budget for each emitted line.

## Effects

- Apps on transports that split long lines, such as Heroku at 10,000 bytes, can keep every line a single valid JSON object.
- Apps that do not set the budget see no change in output.
