# Release 1.3.3

## Decisions

Cut 1.3.3 from `main`. Ship the encode-path switch from `JSON.fast_generate` to `JSON.generate` so boot and emit work under json 3. Keep gemspec `json (>= 2.21.2)`. Leave tag and RubyGems publish to `make release` after a clean commit.

## Effects

VERSION is 1.3.3. CHANGELOG section dated 2026-11-10. PATH gem entries in `Gemfile.lock` and appraisal lockfiles point at 1.3.3. Gem package builds at 28160 compressed bytes across 23 packaged paths; encode sources call `JSON.generate` only. Regression covers simple-string and large structured-hash encode when `fast_generate` is absent. Base/head bench on json 2.21.2 shows no encode regression; simple path improves by avoiding deprecation warnings. Dependency-audit recommendations (Rails lock bumps, orphan gemfiles, soft railties) stay open and are not part of this cut.

## Next

Push `main`, then run `make release` to test, push the gem, tag `1.3.3`, and create the GitHub release. RubyGems still serves 1.3.2 until publish. Consumer apps that pinned json to 2.x only for this break can drop that pin after locking 1.3.3.
