## Effects

Version is 1.3.1. CHANGELOG Unreleased is empty. Lockfiles list the path gem as 1.3.1.

Dedicated benchmark, 10000 iterations unless noted:

Simple messages: JsonLogger 0.0375s, ActiveSupport::Logger 0.0069s, overhead 441.09 percent.

Hash messages: JsonLogger 0.0626s, ActiveSupport::Logger 0.0115s, overhead 445.02 percent.

Tagged logging: tagged 0.0535s, untagged 0.028s, overhead 90.79 percent.

Context scope: with context 0.0798s, without 0.0279s, overhead 185.55 percent.

Sanitization, 1000 iterations: large hash 2.54KB 0.1546s, simple 0.0031s, overhead 4811.75 percent.

Memory, 10000 hash lines: 12109KB allocated, 140006 objects, 0KB retained, 1.21KB per log, 14.0 objects per log.

The 1.2.3 trace recorded about 11 objects per hash line and lower simple-message overhead. Extra copies on the encoder and context paths explain the extra objects. Variance versus the earlier polyrun bench on the same tree is expected.
