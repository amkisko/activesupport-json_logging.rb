# Lineage and consumers

Run this companion when a named object, contract field, or reported number is in scope. Skip when the tree has no data path and no published contract, and state that reason. Keep the same finding fields.

## Consumer map

If a named object changes, list direct consumers, indirect consumers, and form-sensitive downstream derivations. Treat those updates as the same fix. A local fix that breaks a consumer is a failed fix.

## Number lineage

Trace raw input to intermediates to the number a person is shown. Hardcoded table cells are findings. Skip when the tree has no data path.

A later artifact does not prove an earlier gate. When a gate fails, downstream artifacts are dirty even if they still exist. When code or a document says similarly, same as, or exactly as in, require a diff of what changed and a re-check of those lines.
